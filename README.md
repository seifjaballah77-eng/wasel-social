# Seif Messages — private messaging MVP

واجهة عربية بسيطة للدردشة عبر الإنترنت باسم Seif Messages باستخدام GitHub Pages وSupabase. التركيز الحالي هو الرسائل النصية والصور والرسائل الصوتية المسجلة؛ **المكالمات الصوتية مؤجلة ولم تُنفّذ بعد**.

## ما الذي يدعمه الكود الحالي؟
- تسجيل دخول مجهول عبر Supabase، مع ملف مستخدم تلقائي.
- إظهار حالة الاتصال أثناء فتح الموقع والاتصال بقناة Realtime.
- محادثة مباشرة ورسائل نصية محفوظة في قاعدة البيانات.
- إرسال الصور والرسائل الصوتية المسجلة عبر تخزين خاص، مع روابط مؤقتة للعرض.
- منشورات وصور عامة داخل النسخة التجريبية.

## إعداد ضروري قبل أن يعمل الموقع
**التعديلات البرمجية وحدها لا تكفي.** يجب ربط الموقع بمشروع Supabase حقيقي:

1. أنشئ مشروعًا في https://supabase.com/ أو افتح مشروعك الحالي.
2. من Authentication > Sign In / Providers فعّل Anonymous Sign-Ins.
3. افتح SQL Editor ونفّذ محتويات `schema.sql`. هذا الملف يضيف/يحدّث جدول الرسائل وسياسات تخزين الصور والملفات الصوتية.
4. من Project Settings > API انسخ Project URL ومفتاح anon/publishable فقط.
5. افتح `app.js` واستبدل القيمتين `YOUR_SUPABASE_PROJECT_URL` و`YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY` بالقيم الصحيحة.
6. تأكد من أن Realtime مفعّل لجدولي `messages` و`posts` (يحاول ملف SQL إضافتهما إلى publication).
7. انشر تغييرات `main` عبر GitHub Pages: Settings > Pages > Deploy from a branch > `main` > `/(root)`.

الرابط المتوقع بعد تفعيل GitHub Pages:
https://seifjaballah77-eng.github.io/wasel-social/ (اسم المستودع والرابط لم يتغيرا)

## اختبار فعلي بين بلدين/جهازين
1. افتح الرابط في متصفحك وانتظر ظهور معرّف حسابك.
2. أرسل الرابط إلى الشخص الآخر واطلب منه فتحه في متصفح يدعم الاتصال بالإنترنت.
3. يجب أن يظهر كل حساب في قائمة الآخر؛ ظهور «متصل الآن» يعتمد على بقاء الصفحة مفتوحة والاتصال بالخدمة.
4. أرسل رسالة نصية، ثم جرّب صورة صغيرة. اختبر أيضًا بعد تحديث الصفحة للتأكد من حفظ الرسائل.
5. إذا لم يظهر الحساب أو فشل الإرسال، راجع رسالة الخطأ في الموقع وإعدادات Supabase. لا يمكن اعتبار التطبيق جاهزًا قبل اجتياز هذه الاختبارات على جهازين مختلفين.

## حدود وأمان
- المكالمات الصوتية غير موجودة في هذه المرحلة، وستُضاف لاحقًا إذا رغبت.
- الرسائل الفورية تعتمد على اتصال الإنترنت وخدمة Supabase؛ لا يمكن ضمان وصولها عندما يكون جهاز المستلم غير متصل، لكنها تُحفظ ليقرأها عند عودته.
- تسجيل الدخول المجهول لا يضمن هوية الشخص، ولا يربط تلقائيًا الحسابات بين الأجهزة.
- النسخة أولية؛ قبل الاستخدام العام أضف حماية من الإساءة ومعدلات إرسال محدودة وقيودًا أدق لاكتشاف المستخدمين. لا تضع مطلقًا مفتاح `service_role` أو أي مفتاح سري في ملفات الموقع.
